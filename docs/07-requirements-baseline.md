# 第一版需求基线

- 版本：v0.1
- 日期：2026-11-17
- 输入样本：`assets/references/private/seed-defense-transcript-2026-11-15.txt`
- 目标：两周内完成一条可演示、可评估的项目答辩复盘闭环

## 1. 产品范围

第一版服务一个明确场景：

> 学生完成软件项目答辩或模拟问答后，导入记录，生成问题卡，完成语音反思和重答。

第一版不实现：

- 实时 AI 评审。
- 实际面试中的隐藏式答案提示。
- 多角色评审大厅。
- 复杂组织后台。
- 移动原生 App。

## 2. 核心用户流程

```text
导入问答文本
→ 提取问题与追问
→ 生成问题卡
→ 标注考察点和回答缺口
→ 语音反思
→ 重新回答
→ 查看前后对比
→ 进入复习队列
```

## 3. 功能需求

### FR-01：创建复盘场次

用户可以创建一次答辩复盘，记录场次名称、日期、项目名称和场景类型。

验收标准：

- 必填字段为空时不能创建。
- 创建成功后进入场次详情页。
- 场次数据刷新后仍然存在。

### FR-02：导入问答记录

用户可以粘贴纯文本，首版至少支持一种固定格式的转写文本。

验收标准：

- 粘贴内容后可以预览字符数。
- 支持识别“用户”“AI 评审”“教授”“专家”等发言角色。
- 导入失败时显示具体原因。
- 原始文本默认只保存在本地或用户账户私有空间。

### FR-03：提取问题和追问

系统从转写文本中提取问题、回答和追问关系。

验收标准：

- 识别出问题文本和对应回答。
- 同一题组的追问与原问题关联。
- 每个问题保留原文位置或时间信息。
- 用户可以手动拆分、合并和修改问题。

### FR-04：生成问题卡

每个问题生成结构化卡片。

验收标准：

- 包含原始问题、回答摘要、问题类型、考察点、证据缺口和复盘状态。
- 考察点和缺口可以点击查看原文依据。
- AI 不确定时显示低置信度。
- 用户可以修改分类和状态。

### FR-05：识别回答缺口

系统标记回答中的结构和证据问题。

首版至少支持：

- 没有明确结论。
- 没有数据或测试条件。
- 只讲团队，不讲个人贡献。
- 没有边界或兜底。
- 前后口径不一致。
- 遇到盲区但没有诚实收口。

### FR-06：语音反思

用户可以在问题卡上录制语音反思。

验收标准：

- 支持开始、暂停、停止和重录。
- 录音可以转写为文字供用户编辑。
- 反思内容与问题卡关联。
- 用户可以删除录音和转写。

### FR-07：重答与对比

用户可以重新回答一个问题，并查看第一次与第二次的差异。

验收标准：

- 新回答保存为独立记录。
- 对比至少包含结论、证据和边界三个维度。
- 用户可以标记“更有帮助”的具体变化。
- 重答后可以更新掌握状态。

### FR-08：复习队列

系统根据问题状态生成复习任务。

验收标准：

- 首页显示待复习数量。
- 支持按问题类型和掌握状态筛选。
- 显示至少一个重复出现的高频主题。
- 可以随机抽取问题进入重答模式。

### FR-09：成本可观测

系统记录每次复盘的模型调用和成本。

验收标准：

- 显示模型调用次数。
- 显示输入 token、输出 token 和估算费用。
- 显示处理耗时和失败调用。
- 用户可以设置单场调用上限。

### FR-10：隐私与导出

用户可以删除、导出自己的数据。

验收标准：

- 支持删除原始文本、录音和问题卡。
- 支持导出 Markdown 或 JSON。
- 导出文件不包含系统密钥。
- 私有参考材料不会被自动提交到 Git。

## 4. 非功能需求

| 类别 | 要求 |
|---|---|
| 可解释性 | 关键分析必须能追溯到原文或时间点 |
| 隐私性 | 原始材料和录音默认私有，支持删除和导出 |
| 成本 | 单场主要模型调用目标为 3 到 5 次 |
| 性能 | 文字导入后 60 秒内返回首版问题卡；更长处理使用异步状态 |
| 可恢复性 | 失败任务可重试，不重复计费或覆盖已有结果 |
| 可维护性 | 提示词、分类和数据结构有版本号 |
| 可移植性 | 支持 Docker 本地运行 |

## 5. 样本验收目标

使用种子样本验证时，第一版目标为：

- 提取约 20 个题组，允许人工修正。
- 识别至少 10 条追问关系。
- 正确标注至少 6 个主要缺口：运维、中间件、性能证据、服务端容灾、理论依据、口径一致性。
- 为每个高严重度问题生成一次反思提示。
- 完成至少 1 次重答和前后对比。
- 单场模型调用和费用可见。

## 6. 第一轮演示脚本

1. 导入种子样本。
2. 展示系统识别出的 20 个题组。
3. 选择一个架构选型问题，展示追问链和考察点。
4. 选择一个服务端容灾问题，展示回答偏移和缺口。
5. 选择一个性能问题，展示“只有单点测试数据”的证据不足。
6. 录制一段语音反思。
7. 重新回答其中一个问题。
8. 展示第一次和第二次回答的差异。
9. 展示本周三个高频弱点。
10. 展示本次模型调用和估算成本。

## 7. 暂不排期

- 实时语音识别。
- 实时问题提示。
- 多角色评审。
- 相似问题自动聚类。
- 用户邀请和协作。
- 自动生成完整标准答案。
- 视频画面分析。
