# 种子问题库 v0.1

- 来源：`assets/references/private/seed-defense-transcript-2026-11-15.txt`
- 用途：验证问题提取、意图分类、追问链和回答缺口分析
- 说明：以下问题为结构化摘要，不是原始全文摘录

## 1. 问题分类

| 类型 | 说明 |
|---|---|
| 决策依据 | 为什么选这个方案，为什么不选另一个 |
| 证据核验 | 数据、阈值、测试条件和来源是否可靠 |
| 个人贡献 | 哪些是团队完成，哪些是本人负责 |
| 运维责任 | 上线后谁维护，如何巡检和响应故障 |
| 故障边界 | 单点故障、降级、容灾、恢复和补偿 |
| 架构理论 | 术语、模式和理论是否理解准确 |
| 演进判断 | 何时拆分、先拆什么、依据是什么 |
| 成本权衡 | 技术选择带来的成本、人力和复杂度 |
| 定义澄清 | 组件名称、职责和边界是否准确 |
| 优先级判断 | 先做什么，为什么 |

## 3. 首版自动分析要求

产品至少应识别：

- 一个问题后续有几次追问。
- 追问是否在要求证据、量化、边界或反例。
- 回答是否给出了明确结论。
- 回答是否出现前后矛盾。
- 回答是否只讲团队而没有个人贡献。
- 回答中哪些内容属于实测、推演或概念解释。
- 哪些问题属于同一能力主题。

## 4. 首版不要求做到

- 自动判断用户是否“能力不足”。
- 自动给出唯一正确架构。
- 自动生成完美的整段答辩稿。
- 在没有测试数据时虚构性能数据。
- 从语音中推断用户情绪或人格。
